# Mini CRM commercial

Mini CRM simple, moderne et responsive, construit avec **Next.js + TypeScript + Tailwind CSS**.

## Fonctionnalités

- Dashboard synthétique
- Page clients
- Page visites
- Page relances
- Page devis
- Données d'exemple locales (sans backend externe)

## Lancer localement

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.
